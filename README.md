
# IPL Cricket Data Analysis (2008–2026)

## Project Overview
This project analyzes Indian Premier League (IPL) cricket data using Python.
It focuses on player performance, team performance, match statistics,
and season-wise trends.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset
- matches.csv
- deliveries.csv

The datasets contain IPL match details and ball-by-ball information.

## Key Analysis
1. Top 10 Run Scorers
2. Top 10 Wicket Takers
3. Highest Individual Score
4. Most Successful Teams
5. Most Wins by a Team
6. Toss Decision Analysis
7. Player of the Match Analysis
8. Batting vs Bowling Performance
9. Season-wise Run Comparison

## Visualizations
- Top 10 Run Scorers – Bar Chart
- Top 10 Wicket Takers – Bar Chart
- Season-wise Runs – Line Chart
- Toss Decision – Pie Chart

## How to Run
1. Install required libraries:
   pip install pandas numpy matplotlib seaborn

2. Run the project:
   python main.py

## Conclusion
This project provides insights into IPL cricket statistics,
player performances, team achievements, and season-wise trends
through data analysis and visualization.
